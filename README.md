# Translogística — Demo pública

Versión **estática** para evaluar la interfaz, el diseño y la navegación de Translogística.

**URL prevista:** https://pixelforge-proyecto.github.io/translogistica-demo/

Conserva la portada de Laravel, CSS de Vite y los recursos gráficos de la segunda entrega. La vista de login es demostrativa y no recopila contraseñas.

**No ejecuta Laravel/PHP ni se conecta a MySQL**. Los contactos reales están ocultos en esta demo. Para recopilar opiniones, agregar un Google Forms externo con consentimiento de las personas que participan.

## Activar GitHub Pages

Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save.

**Nota:** `images/camion-hero-banner.png` debe copiarse del ZIP de publicación de la demo; es la fotografía original del camión. Sin ella se verá un fondo de degradado alternativo.
